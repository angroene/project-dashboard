**Conclusion.** No copyleft, no commercial and no network-use license was found in the production or web-bundle trees.
Everything is MIT, ISC, BSD, Apache-2.0, BlueOak-1.0.0, Unlicense or Zlib, compatible with distributing this project
under Apache-2.0.

Resolved: `exceljs@4.4.0` asks for `unzipper@^0.10`, whose `binary` dependency pulled in `buffers@0.1.1` (no license
at all) and `chainsaw@0.1.0` (`MIT/X11`). `package.json` overrides `unzipper` to `0.12.3`, which no longer depends on
`binary`, so neither package is installed. exceljs only uses unzipper in its streaming reader, which this project does
not call (workbooks are loaded with `workbook.xlsx.load`); the Excel round-trip tests pass with the override.
Remove the override once exceljs depends on a fixed unzipper.

Also noted, no action needed:

- `jszip` is `(MIT OR GPL-3.0-or-later)`: used under the MIT option.
- `pako` is `(MIT AND Zlib)`: both permissive.
- `crc-32` and `readdir-glob` are Apache-2.0 (via exceljs).

**NOTICE file: not required.** Apache-2.0 section 4(d) obliges redistributors to carry forward the contents of a
`NOTICE` file that a dependency ships. No package in either tree ships one (the NOTICE column below is empty), so there
is nothing to carry forward, and a NOTICE with this project's own copyright statement is optional, so none was invented.
Re-run `npx tsx scripts/licenses.ts` after dependency changes: if a NOTICE-bearing package appears, create a
`NOTICE` file with its contents.

**Attribution when redistributing.** MIT, ISC and BSD licenses require the copyright and permission notice to
accompany copies. A source checkout plus `npm ci` keeps each package's own license file in `node_modules`; the Docker
image copies `node_modules` and this report. The built UI (`dist/web`) bundles React, React DOM, TanStack Query
and react-markdown with their dependencies as minified code without their license headers, so ship this file (or the
licenses themselves) with any distributed build of the UI.

**Not covered.** This reads declared metadata only. It does not inspect source headers, bundled fonts or images, or
the licenses of build and test tooling (not redistributed). It is not legal advice.
